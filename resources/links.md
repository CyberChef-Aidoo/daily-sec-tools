# 🔗 Resources

Shared reference links for the team — cheat sheets, lab environments, and learning platforms.

## 🧪 Practice Labs *(safe, legal environments)*

| Platform | Why use it |
|---|---|
| [TryHackMe](https://tryhackme.com/) | Guided rooms, great for beginners |
| [Hack The Box](https://www.hackthebox.com/) | More self-directed, wide range of difficulty |
| [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) | Intentionally vulnerable web app |
| [Metasploitable2/3](https://github.com/rapid7/metasploitable3) | Intentionally vulnerable VM |
| [PentesterLab](https://pentesterlab.com/) | Focused web/app security exercises |
| [PicoCTF](https://picoctf.org/) | Beginner-friendly CTF challenges |
